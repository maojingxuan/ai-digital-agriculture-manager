# 第一阶段：全局农小贝与交互基础

实施日期：2026-10-06。直接修改原项目，未建立备份或额外工作副本，未改动业务数据库与模型资产。

## 已交付

- 首页主舞台与其他页面的悬浮农小贝。悬浮助手支持展开对话、收起、隐藏及再次显示。
- 对话、输入草稿、当前请求、展示偏好由登录区域的 `AssistantProvider` 统一持有；普通页面切换不清空。退出或切换账号会卸载并清理会话。
- 单个 Three.js 画布固定挂载在路由之外。首页通过舞台占位区域的尺寸定位画布，其他页面调整为悬浮布局，不移动挂载点或重新加载模型。隐藏时保留实例但暂停渲染；离屏、后台页面也暂停渲染。
- 现有 Idle / Listening / Thinking / Talking 动作按交互驱动；手动动作按钮仅在开发模式的“开发调试”中显示。关闭调试或离开首页恢复自动动作。
- 自动眨眼、轻微视线变化、全身/半身/特写镜头、镜头复位、减弱动画。
- 文字对话与任务提示、模型加载失败提示和重试、服务失败重试、60 秒等待超时、停止等待、重复发送保护。
- 保留原有手动浏览器播报，但不自动播放声音，也未接入豆包、麦克风或新的语音服务。没有声音时不因文字回答而自动播放讲话动作。

## 状态和事件约定

| 事件 | 任务状态 / 动作 | 行为 |
| --- | --- | --- |
| 登录就绪 | idle / Idle | 初始化欢迎对话 |
| 输入框聚焦 | listening / Listening | 临时提示输入；失焦恢复此前任务，不丢失完成状态 |
| 发送问题 | analyzing / Thinking | 禁用重复发送；允许跨页和停止等待 |
| 收到回答 | complete / Idle | 添加实际接口回复，不自动讲话 |
| 请求失败或超时 | error / Idle | 显示原因，允许重试最近问题 |
| 停止等待 | idle / Idle | 中止前端请求并忽略迟到回复；服务器已开始的操作可能继续，不能承诺撤销业务写入 |
| 用户点击原有浏览器播报 | 保留任务 / Talking | 仅实际播报启动时进入 Talking；结束、停止、报错恢复自动动作 |
| 退出账号 | 卸载 | 中止等待、取消播报、释放渲染资源、清空会话 |

`patrolling / warning / diagnosing / reporting` 已保留状态命名，后续接入实际巡田和诊断事件；本阶段没有伪造这些步骤或诊断结果。

## 文件入口

- `apps/web/src/assistant/`：全局状态、主舞台/悬浮布局、共用对话、镜头与开发调试控制。
- `apps/web/src/components/NongxiaobeiAvatar.tsx`：持续渲染实例、视线、眨眼、镜头与失败恢复。
- `apps/web/src/App.tsx`：登录区域挂载全局助手。
- `apps/web/src/pages/DashboardPage.tsx`：首页新布局及现有数据展示。
- `apps/web/src/services/api.ts`：对话和服务状态请求支持 AbortSignal，保持原接口契约。
- `scripts/stage1-ui-fixture.mjs`：仅供界面验证的本地静态服务和测试回复，不加载 .env、不连接数据库、不调用 AI 服务，不是正式后端。

## 验证方法

在项目根目录执行 `npm run typecheck`、`npm run lint`、`npm run build`。

可选界面测试：先构建前端，运行 `node scripts/stage1-ui-fixture.mjs`，打开 `http://localhost:4173`。页面内的管理员/普通用户为虚拟测试身份，所有回复明确为测试回复。该脚本不验证真实权限或实际 Agent 工具。

- 输入“测试失败”：首次返回服务失败，点击重试后恢复。
- 输入含“慢速”的问题：8 秒后回复，可检查跨页等待、取消和迟到回复隔离。
- 输入含“超时”的问题：65 秒后回复，用于检查前端 60 秒超时及迟到回复隔离。
- 使用 `--model-failure-once` 启动：首次模型请求失败，点击“重新加载模型”可恢复。可用 `STAGE1_UI_PORT` 指定另一测试端口，始终仅监听本机。

正式运行仍用原有启动方式 `npm run dev`，不能用测试脚本代替正式服务。

## 范围和限制

- 当前会话只保留在当前登录页面会话中，刷新浏览器会重新开始；没有新增服务器历史会话存储。
- 悬浮面板是覆盖式交互，页面底部预留空间；需要操作被覆盖区域时可收起或隐藏，隐藏按钮保留为小入口。没有修改原有业务表单和权限规则。
- 五音口型和三种情绪形变尚未实施，现有 GLB 未替换；更丰富舞台演出属于第三阶段。
- 自主巡田主剧情、真实图片推理、公开数据集训练、真实设备均未在本阶段实施。旧问诊页面中的能力描述与低置信度问题仍需按后续阶段修正。
- UI 验证使用测试接口，不等于正式后端业务、数据库持久化、收费模型调用、硬件或真实权限回归通过。
- 构建仍提示 Three.js 相关懒加载块超过 500 kB；本阶段已按单实例和离屏暂停减少重复占用，没有做长期性能或 WebGL 上下文丢失故障压测。
