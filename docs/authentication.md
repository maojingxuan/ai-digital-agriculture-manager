# 登录与权限

系统使用数据库账号、Scrypt 密码哈希和带过期时间的 HMAC 签名登录凭证。业务 API 默认要求登录，服务端每次请求都会重新读取数据库中的真实角色，不信任前端传入的用户编号或角色。

## 角色权限

| 功能 | 普通用户 | 管理员 |
| --- | --- | --- |
| 查看环境与设备状态 | 是 | 是 |
| 问诊、巡田、产品新增 | 是，仅归属当前账号 | 是 |
| 查看业务历史 | 仅自己的记录 | 全部记录 |
| 查询知识库 | 是 | 是 |
| 上传、录入、删除知识 | 否 | 是 |
| 下发设备控制命令 | 否 | 是，且必须二次确认 |
| 查看设备命令审计 | 否 | 是 |

## 本地演示账号

- 管理员：`farmer@example.com` / `Admin@123456`
- 普通用户：`user@example.com` / `User@123456`

默认密码仅用于本地演示，登录后应在“系统设置”中修改。首次执行 `npm run setup` 会为本机生成随机 `AUTH_SECRET` 并写入不会提交 Git 的 `.env`。

如已有数据库，执行以下命令会补齐登录账号和角色，不会清空业务数据：

```bash
npm run db:migrate
npm run db:seed
```

## 设备控制安全

设备控制同时检查管理员角色、命令与设备类型是否匹配，以及 `confirmExecution=true` 的明确确认。每次成功命令都会记录操作账号、命令参数、执行状态和时间。通过智农 Agent 控制设备时也执行同样的管理员角色检查，并保留原有的确认步骤。
