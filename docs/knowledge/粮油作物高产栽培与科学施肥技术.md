# 粮油作物高产栽培与科学施肥技术

来源：农业农村部种植业管理司、全国农业技术推广服务中心、农业农村部科学施肥专家指导组《2023年小麦水稻玉米马铃薯春夏季科学施肥指导意见》。本知识覆盖小麦、水稻、玉米三大主粮作物的分区科学施肥技术，核心原则是测土配方施肥、有机无机结合、氮肥分次施用。

## 一、小麦科学施肥技术

（一）核心原则：根据苗情长势和土壤墒情分类指导，因地、因苗、因时追肥；分次施用氮肥，适当增加拔节中后期的施用比例；肥水管理一体化，土壤墒情好则趁墒施肥。（二）华北平原灌溉冬麦区：返青前每亩总茎数小于45万的三类麦田，春季分两次追肥，返青期随浇水每亩追施尿素6～8公斤，拔节期再追尿素7～10公斤；总茎数45～60万的二类麦田，起身期结合浇水每亩追施尿素10～15公斤；总茎数60～80万的适宜麦田，拔节期追施尿素10～13公斤；旺长麦田（总茎数大于80万）推迟并减少氮肥，拔节后期每亩追尿素8～10公斤。受冻麦田低温结束后及早追肥，每亩结合灌水追尿素7～10公斤或磷酸二铵5公斤，或叶面喷施1%～2%尿素溶液50～70公斤。（三）小麦灌浆期叶面喷施磷酸二氢钾、硼肥和锌肥，预防干热风和倒伏，提高灌浆强度增加粒重。（四）长江中下游麦区按目标产量分级追肥：亩产300公斤以下追尿素6～8公斤，300～400公斤追8～10公斤，400～550公斤追尿素10～12公斤加硫酸钾4～6公斤，550公斤以上追尿素13～15公斤加硫酸钾6～8公斤。（五）缺硫地区追肥选用硫酸铵，每亩20～25公斤。

## 二、水稻科学施肥技术

（一）核心原则：控制氮肥总量、合理分配氮肥施用时期，适当增加穗肥比例；基肥深施，追肥"以水带氮"；提倡秸秆还田与化肥科学配施，连续秸秆还田可减少穗肥氮量10%、钾肥30%～50%；增施有机肥，有机无机相结合。（二）氮肥运筹比例：基肥占50%～60%，分蘖肥占20%～30%，穗肥占20%～30%；磷肥全部作基肥；钾肥基肥占50%～60%、穗肥占40%～50%。各稻区按产量水平确定氮肥用量，如长江中下游单季稻区亩产500公斤以下氮肥（N）8～10公斤，500～600公斤10～12公斤，600公斤以上12～18公斤。（三）机插秧侧深施肥可实现施肥插秧一体化，氮肥用量可减少10%～20%；施用缓释配方肥的田块氮肥用量可减少10%。东北寒地稻区推荐含控释养分的26-11-16配方肥，机插秧一次侧深施肥每亩23～30公斤。（四）诊断施用蘖肥和穗肥：遇长时间15℃以下低温、分蘖不足时补施含锌硫酸铵5～7公斤/亩（总氮不超过1.3公斤/亩）；穗肥在幼穗长0.5～1.0厘米时按叶片长势分级施用尿素2～5公斤/亩配氯化钾2～4公斤/亩，叶片披垂田块先晒田7～10天再施肥。（五）高产水稻齐穗和灌浆期可叶面喷施磷酸二氢钾、氨基酸钙镁肥促进灌浆结实。酸性土壤田块基施含硅碱性肥料或生石灰30～50公斤/亩。

## 三、玉米科学施肥技术

（一）核心原则：依据测土配方施肥结果确定氮磷钾与中微量元素合理配比；氮肥分次施用，肥料深施；增施有机肥并机械深施，长期秸秆还田地块适当减少施钾量；重视硫、锌等中微量元素的施用；肥料施用与种肥同播、合理增密等高产栽培技术相结合。（二）华北及黄淮海夏玉米区：种肥同播一次性施肥推荐28-6-9（N-P2O5-K2O）或相近配方，亩产800公斤以上施配方肥50～60公斤、硫酸锌1～2公斤，600～800公斤施45～50公斤，400～600公斤施40～45公斤，400公斤以下施30～40公斤。（三）东北冷凉春玉米区：推荐14-18-13或相近配方，亩产500公斤以下基施配方肥18～23公斤、七叶期追施尿素9～11公斤，500～600公斤配方肥23～28公斤、追尿素11～13公斤，600～700公斤配方肥28～32公斤、追尿素13～16公斤，700公斤以上配方肥32～37公斤、追尿素16～18公斤。（四）东北半湿润春玉米区基追结合：推荐15-18-12配方肥，大喇叭口期追施尿素；一次性施肥推荐29-13-10配方肥，亩产800公斤以上需含30%释放期50～60天的缓控释氮素，配方肥47～53公斤/亩。（五）东北半干旱区可采用膜下滴灌水肥一体化技术，氮肥深施深度8～10厘米，少量多次灌水施肥，减少底（基）肥用量。

## 四、马铃薯科学施肥要点

（一）增施有机肥，有机无机配合施用，由畜禽有机肥提供的氮素建议不超过施氮总量的30%；不建议施用含氯较多的肥料。（二）磷肥全部作基肥一次性施入；钾肥分次施用，K2O用量6公斤/亩以上时50%基肥、50%块茎萌发期追施。（三）具备滴灌喷灌条件的田块实施水肥一体化：氮肥总量12公斤/亩以上时，在播种期、出苗期、块茎形成期、初花期、块茎膨大期分5次施用，比例约30%、30%、20%、10%、10%。（四）种肥或基肥播种前条深施于种子侧或正下方5～7厘米；雨养田块追肥采用机械条施于苗侧后培土覆盖。南方春作马铃薯区缺硼缺锌土壤可基施硼砂1公斤/亩或硫酸锌1公斤/亩。
