# 温室大棚温湿度与光照调控管理

来源：农业农村部种植业管理司与全国农业技术推广服务中心《北方春季蔬菜生产管理技术指导意见》（2023年）、《蔬菜冬季生产技术指导意见》（2024年）。本知识聚焦日光温室与塑料大棚的温度、湿度、光照调控与灾害性天气应对。

## 一、温度管理

（一）适宜温度区间。日光温室越冬茬蔬菜白天室内温度控制在26～32℃，前半夜温度控制在18～20℃，凌晨最低温度控制在12℃以上。冬春茬瓜果类蔬菜生长前期白天温度控制在28～30℃，夜间最低温度控制在13～15℃，长势强的可适当降低夜温，长势弱的适当提高夜温。塑料大棚春提早蔬菜白天气温控制在25～32℃，夜间最低气温控制在10℃以上。露地早春果菜类蔬菜苗期白天气温不超过25℃，夜间8～10℃。

（二）保温措施。夜间室外气温低于10℃时，日光温室要及时覆盖保温覆盖物，保证温室内夜间气温15℃以上。冬季采取顶部通风，在通风口下方悬挂缓冲膜，通风时逐渐增加通风量，温室门口和前屋面处悬挂薄膜减少冷风伤害。雨雪天气时在保温被外覆盖塑料薄膜，确保保温被干爽。连续阴天及强降温等极端天气时采取多层覆盖保温，必要时使用高压钠灯、热风炉、加热风机、燃烧增温块等临时加温。增温块每亩用量10块，于凌晨1点左右点燃；热风机可于夜间10点和凌晨2点左右分别工作1.0～1.5小时。

（三）防寒抗冻。寒潮来临前可喷施芸苔素内酯等植物生长调节剂，增强作物防寒抗冻能力。对受冷害或冻害的植株，可喷施含中微量元素的氨基酸叶面肥或低温诱抗剂。露地蔬菜寒潮前选择晴朗天气浇灌，增加土壤热容量，缓解低温影响。

## 二、湿度管理

（一）高湿危害。棚内湿度过高是诱发灰霉病、霜霉病、疫病等病害的重要原因，应合理控制室内空气湿度，防止湿度过高诱发病害发生。

（二）通风排湿。外界气温低时，可在保温被揭开后进行短时间的顶部通风排湿，每次时间不超过20分钟，然后根据作物生长状况和室内温度情况进行通风管理。连续阴雨雪天气时可选择在中午12～13时、室内温度最高时段通风10～20分钟。南方塑料大棚在不影响棚内温度前提下尽量增加通风量，将棚内空气湿度控制在85%以下。

（三）降低湿度栽培措施。尽量采用膜下滴灌或微喷灌进行灌溉，在行间覆盖稻壳、玉米秸等吸湿物料，必要时在垄沟铺盖碎秸秆。有条件的棚室可安装电除雾、除湿机等除湿设备。连阴天尽量不浇水，防止沤根死苗。

## 三、光照管理

（一）延长光照时间。随着外界温度升高，尽量早揭晚盖保温被。在确保温度前提下，延长室内光照时间。经常清扫棚膜保证透光率，及时更换老旧棚膜。

（二）散射光利用。遇连续阴雨雪天气，白天无雨雪时可短时间卷起保温覆盖物，提高植株光合效率。久阴乍晴天气，中午前后适当放下保温覆盖物（回苫管理），避免植株失水萎蔫。

（三）补光措施。寡日照地区，温室后坡宜以合适角度张挂反光膜，提高温室北侧光照强度。连续阴雨天气有条件的可进行人工补光。

## 四、水肥协同管理

（一）浇水原则。冬季蔬菜浇水要做到"三浇三不浇"：晴天浇水、阴天不浇，午前浇水、午后不浇，浇小水、不浇大水。应选连续晴天的上午浇水，水温应在10℃以上，避免在连阴天气下浇水。

（二）施肥原则。施肥少量多次，每次水溶肥用量2～5公斤/亩，优先采用有机肥加水肥一体化技术。低温期根系生长缓慢，可施用腐植酸或海藻酸肥提高根系活性，植株长势弱可喷施含糖类、氨基酸类叶面肥。

（三）湿害预防。连阴天棚室内湿度较大时，尽量不要进行掐须、打杈等农事操作，避免病原菌侵染，及时去除老叶、病叶、病果等病残组织并在棚室外无害化处理。

## 五、不同棚型调控差异

（一）日光温室：越冬茬注重保温与排湿平衡，前半夜温度18～20℃，凌晨最低12℃以上；12月至翌年2月白天气温26～32℃，前半夜18～20℃，凌晨最低气温维持在8℃以上。（二）塑料大棚：春提早栽培栽植前20～30天扣棚升地温，10厘米地温稳定12℃以上定植；保温不足时采用"大棚+中棚+小棚"多层覆盖，或用轻型保温材料短期浮面覆盖。（三）南方塑料大棚：棚内湿度控制在85%以下，病虫防控优先采用烟雾剂和粉尘剂，减少施药带来的湿度增加。
