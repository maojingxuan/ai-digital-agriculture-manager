# 土壤改良与科学施肥技术

来源：农业农村部《关于加快农业发展全面绿色转型促进乡村生态振兴的指导意见》（农规发〔2024〕27号）、农业农村部种植业管理司与全国农业技术推广服务中心《2019年果菜茶有机肥替代化肥技术指导意见》、农业农村部种植业管理司与全国农业技术推广服务中心负责人答记者问（三大粮食作物化肥利用率）。本知识覆盖耕地有机质提升、测土配方施肥、有机肥替代化肥与秸秆生物反应堆技术。

## 一、耕地质量提升总要求

推进耕地有机质提升，综合采取秸秆还田、畜禽粪肥还田、种植绿肥还田等措施，提高耕地地力和产出能力。深入实施国家黑土地保护工程和东北黑土地保护性耕作行动计划，分区分类开展农田基础设施建设、土壤侵蚀防治、肥沃耕作层培育。测土配方施肥技术推广是提高化肥利用率的重要基础，通过"测、配、产、供、施"五大环节系统推进，广泛开展土壤测试、不断优化肥料配方，推动施肥建议向"一田一策"升级，推进配方肥下地。

## 二、增施有机肥要点

推行有机肥投入推荐用量指导制度，指导种植户科学施用有机肥。鼓励大中型养殖场及周边村镇参照《畜禽粪便堆肥技术规范》（NY/T 3442）堆制有机肥，就地就近还田利用，降低施用成本。强化有机无机相结合，推广有机肥高效施用机械，提高有机肥利用效率。充分利用农作物秸秆资源，推广水稻秸秆粉碎还田以及甘薯、马铃薯、玉米等作物秸秆覆盖、翻压还田。

## 三、果园"有机肥+配方肥"模式

（一）苹果基肥：施用最适宜时间是9月中旬到10月中旬，晚熟品种采收后越早越好。有机肥用量为腐熟农家肥（羊粪、牛粪等）2000公斤（约6方）/亩，或优质生物肥500公斤/亩，或饼肥200公斤/亩，或腐殖酸100公斤/亩；配合硅钙镁钾肥50～100公斤/亩、硼肥1公斤/亩左右、锌肥2公斤/亩左右；复合肥采用高氮高磷中钾型或平衡型（15-15-15），用量50～75公斤/亩。基肥采用沟施或穴施，沟宽30厘米左右、深40厘米左右。（二）苹果追肥：建议3～4次，第一次3月中旬至4月中旬施硝酸铵钙（或25-5-15硝基复合肥）30～45公斤/亩；第二次6月中旬施平衡型复合肥30～45公斤/亩；第三次7月中旬至8月中旬以高钾配方为主，25～30公斤/亩。（三）果园生草：行间人工种植高羊茅、黑麦草、早熟禾、毛叶苕子等，9月中旬播种最佳；草长到30～40厘米时刈割，留茬10厘米左右，每年刈割2～3次。（四）果园覆草：适宜时期3月中旬至4月中旬，覆草厚度常年保持15～20厘米，树干周围20厘米左右不覆草，黏土地不宜覆草。

## 四、柑橘施肥要点

（一）秋冬季施肥：目标产量每亩2000～3000公斤的柑橘园，每亩施商品有机肥300～500公斤，或腐熟农家肥2～4方，或豆粕饼类腐熟有机肥300～400公斤，配合45%（16-14-15或相近配方）配方肥30～35公斤；晚熟品种秋基肥在果实转色期或套袋前后（一般9月）施用。（二）春季施肥：早中熟品种2月下旬至3月上旬施用，选用45%（20-13-12或相近配方）高氮中磷中钾型配方肥，每亩35～40公斤，配合200～300公斤/亩优质有机肥。（三）夏季施肥：6至8月果实膨大期分次施用45%（18-5-22或相近配方）配方肥，每亩40～50公斤。（四）柑橘园生草：秋季播种苕子、箭筈豌豆等豆科绿肥，每亩播种量2～4公斤，翌年3～4月刈割翻压或覆盖。

## 五、设施蔬菜"有机肥+配方肥"模式

（一）设施番茄：基肥每亩基施腐熟优质农家肥3～4方或商品有机肥350～400公斤，配45%（18-18-9）配方肥30～40公斤；追肥用45%（15-5-25）配方肥每次6～10公斤，分7～10次随水追施。（二）设施黄瓜：基肥农家肥4～5方或商品有机肥400～450公斤，配45%（18-18-9）配方肥40～50公斤；追肥用45%（17-5-23）配方肥每次7～10公斤。（三）设施辣椒：基肥农家肥2～3方或商品有机肥300～350公斤，配45%（18-18-9）配方肥25～30公斤；追肥用45%（15-5-25）配方肥每次10～16公斤，分3～5次。

## 六、"菜-沼-畜"模式

将畜禽粪便、蔬菜残茬和秸秆等物料投入沼气发酵池中，按1:10比例加水稀释，加入复合微生物菌剂进行无害化处理，充分发酵后的沼渣沼液直接作为有机肥施用。设施番茄基肥每亩施沼渣3.5～5方，追肥苗期初花期结合灌溉冲施沼液每亩0.5～1方，坐果期和果实膨大期将沼液和配方肥分5～8次追施。

## 七、秸秆生物反应堆技术

（一）操作时间：晚秋、冬季、早春建行下内置反应堆，最好在作物定植前10～20天做好。（二）行下内置式：在小行位置挖宽约70厘米、深20厘米的沟，填入秸秆高30厘米，撒入150～200公斤饼肥和用麦麸拌好的菌种，覆土18～20厘米，浇大水湿透秸秆，3～4天后用14号钢筋打孔，孔深穿透秸秆层。（三）注意事项：每500公斤秸秆用菌种1公斤；浇水时不要冲施化学农药，特别禁冲杀菌剂；生长期内保持每月打孔一次，每次打孔与前次错位10厘米；减少浇水次数，一般常规栽培浇2～3次水的用该项技术只浇一次水即可。
