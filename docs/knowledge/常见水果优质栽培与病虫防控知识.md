# 常见水果优质栽培与病虫防控知识

来源：全国农业技术推广服务中心与国家苹果产业技术体系《2025年全国苹果园冬季管理技术指导意见》、农业农村部种植业管理司《2023年果树棉花甘蔗春季科学施肥指导意见》、广东省农业农村厅《10种主要果树上半年管理技术要点》。本知识面向果园土肥水管理、整形修剪、花果管理与病虫害防控。

## 一、苹果园管理要点

（一）土壤管理。土层浅薄、土壤贫瘠的果园可利用冬季农闲客土，"以土代肥"每亩压土20～25吨，山丘地压土不宜超过15厘米，沙地压粘土不超过10厘米。压土前先旋耕，促使与原土层融合，避免形成"上下两层皮"。未完成深翻的果园应在上冻前半个月以上深翻改土，深度一般为60～80厘米，土壤疏松的40～50厘米。深翻时可施入作物秸秆等有机物料和有机肥。

（二）科学施肥。按照有机肥为主、化肥为辅、重视中微量元素的原则，一般每亩施用生物有机肥150～200公斤和商品有机肥600～800公斤（或腐熟农家肥1500～2500公斤），硅钙镁钾肥或其他土壤调理剂60～80公斤。土壤缺锌和硼的果园，每亩施用硫酸锌1～1.5公斤和硼砂0.5～1公斤。开沟或挖穴施肥，深度40厘米左右，肥和土混匀后回填。

（三）浇灌封冻水。气温降到3～5度或果园内土壤夜冻昼消时，沿树冠外缘内侧或行间开沟灌水，做到浇水后2～3小时地面无积水，地下40～50厘米土壤湿润，果树根系分布层土壤湿度维持在70～80%左右。

（四）整形修剪。按照上稀下密、外稀内密、大枝稀小枝密的原则修剪，确保伤口平整，修剪后及时清理果园，剪下枝条集中销毁，伤口涂抹愈合剂，树干涂白。矮砧果园主要采用高纺锤或自由纺锤形，疏除粗度超过中央干直径1/3的主枝、与领导头竞争的直立强枝、病虫枝和距地面70厘米以内的分枝。乔化砧果园主要采用小冠疏层或自由纺锤形，角度小的主枝可将基角开至60～70度。

（五）病虫害防控。冬季重点防治腐烂病、轮纹病、顶梢卷叶蛾、金纹细蛾、山楂叶螨、介壳虫、食心虫等。彻底清园：清扫园内及周围病果、落叶、杂草，集中烧毁或深埋。结合冬剪刨除死树病树、刮除翘皮、锯除死枝。树干涂白高度不低于80厘米，全树及地面喷施1～2次5波美度石硫合剂。火疫病疫区果园，病枝修剪处离发病部位应至少达50厘米。

（六）灾害预防。土壤封冻前在果树根颈部位培土，培土高度超过嫁接口。1～3年生幼树用稻草、毛毡或塑料膜包裹主干。降雪后及时从下往上轻轻摇落树冠积雪，避免枝条劈裂。检修加固果园支架、防雹网及防霜设施。

## 二、柑橘管理要点

（一）防寒保树。树盘培土15～20厘米，主干涂白，遇寒潮可覆盖地膜或稻草。受冻树及时剪除冻枝冻叶，喷施芸苔素加磷酸二氢钾恢复树势。

（二）肥水管理。萌芽前10～15天株施腐熟有机肥5～8公斤加氮磷钾复合肥0.5～0.8公斤；谢花后株施高钾复合肥0.3～0.5公斤，忌偏施氮肥；幼果膨大期株施高钾复合肥0.6～1公斤加钙镁肥0.2公斤。保持土壤湿润，干旱时小水勤浇，雨后清沟排水防止沤根。

（三）保果与疏果。谢花后7～10天和20～30天各喷施一次赤霉素加糖醇钙，防止生理落果。疏除弱花穗、过密花穗，谢花后疏除畸形果、小果、病虫果，保证叶果比（砂糖橘50:1、沃柑40:1、贡柑60:1）。

（四）夏梢控制。夏梢萌发是落果主因，人工抹除夏梢每隔5～7天抹一次，或喷施多效唑加烯效唑抑制夏梢萌发。

（五）病虫防控。重点防蚜虫、蓟马、红蜘蛛、炭疽病、溃疡病、潜叶蛾。蚜虫蓟马用啶虫脒，红蜘蛛用阿维菌素加螺螨酯，炭疽病用咪鲜胺，溃疡病用噻唑锌加春雷霉素，交替用药。酸性土壤每亩撒施生石灰50～100公斤调节pH值。

## 三、葡萄管理要点

（一）破眠促芽。使用破眠剂前淋透水，当温度稳定在10℃以上时用药，可选用50%单氰胺20～25倍液喷施挂果母枝，喷后立即大水淋湿全园。

（二）整形与定梢。春芽萌发后每个节位选留一个带花壮旺芽，棚架每平方米定梢6～8条，双篱架每米留梢10～12条，其中营养梢占10%。

（三）花果管理。开花前2～3天疏花，保留花序中部14～16个花序小分枝。每穗葡萄留果40～60粒、重量控制在500～750克，每亩定产1000千克左右。盛花后12～15天用20～50毫克每升赤霉素溶液处理幼穗可增大果粒。

（四）水肥管理。谢花后每隔10～15天施肥一次连施三次，前两次每亩施复合肥10～15千克加硝酸铵钙5～10千克，第三次每亩施复合肥10～15千克加硫酸钾10千克。果实开始着色时每亩施钾肥10千克加硫酸镁5千克。

（五）病虫害防治。灰霉病可选用咯菌腈、嘧霉胺等；炭疽病可选用咪鲜胺、苯醚甲环唑等；霜霉病可选用精甲霜灵、嘧菌酯等；蓟马可用乙基多杀菌素防治。

## 四、香蕉管理要点

（一）水肥管理。香蕉喜水但忌积水，干旱季节每月灌溉3～4次，雨水少时畦沟保留浅水层。抽叶期每10～15天淋一次水溶肥，侧重氮钾。5～6月孕蕾前株施高钾复合肥0.8～1.2公斤加钾肥0.3公斤，抽蕾后、谢花后各施一次壮果肥，侧重钾、钙、硼肥。

（二）断蕾疏果。雌花开完小果坐稳后及时断除多余花蕾，疏除畸形果、过小果、过密果，每穗保留7～9梳，每梳保留10～15个果。

（三）果穗套袋。疏果后立即用双层防水套袋（内层无纺布、外层塑料膜）套果穗，防止病虫侵害、暴雨冲刷和日灼。

（四）病虫害防治。花叶心腐病为病毒病，主要由蚜虫传播，蚜虫可用啶虫脒防治，及时清除病株并在地面撒生石灰。枯萎病可通过选择无病地块、选用抗病品种、淋施枯草芽孢杆菌预防。

## 五、施肥通用原则

果树施肥以有机肥为基础，提倡有机无机配合施用；依据土壤测试结果适当调减氮磷钾化肥用量，增加钙、镁、硼和锌的施用；施肥与高产优质栽培相结合，如起垄栽培、果园生草、下垂果枝修剪等。
